# CONDUCTOR v4 案件別SAR解析基盤：構想整理メモ

> 本文書はv4設計の構想入力である。確定した実装契約は
> `CONDUCTOR_v4_design_spec.md`、行動指針は`CONDUCTOR_v4_policy.md`を正とする。

## 1. 目的

本基盤の目的は、案件ごとに蓄積される化合物構造と活性データを対象に、AIエージェントが多様な視点から網羅的にSAR（Structure–Activity Relationship）を解析し、人間の研究者が見落としやすい関係性や仮説候補を抽出することである。

従来のSAR解析は、研究者の経験や着眼点に強く依存する。これは有用である一方、以下の制約を持つ。

- 人間が最初から注目した構造系列や仮説に解析が偏りやすい
- 高次元かつ多様な表現空間を横断して調べることが難しい
- 多数の局所グループを網羅的に比較することが難しい
- 人間が普段選ばない表現と解析の組合せを試しにくい

本基盤では、AIエージェントの強みを「人間の先入観に依存せず、広く、深く、反復的に探索できること」と捉える。

最終的な目的は、AIが自律的に最終結論を確定することではなく、以下を実現することである。

1. 構造と活性の間に潜む関係性を幅広く探索する  
2. 人間が気づきにくい局所的SARや例外を発見する  
3. 複数の解析結果から仮説候補を整理する  
4. 活性向上につながる構造変換や次の検討方向を人間に提示する  
5. 最終的な判断は、ベテラン研究者の解釈と統合する  

---

## 2. 全体アーキテクチャ

本基盤は、以下の4段階で構成する。

1. **表現生成**
2. **文脈化／グルーピング**
3. **解析オペレーター**
4. **解釈（Interpretation）**

### 英語名称の候補

| Step | 日本語 | 英語候補 |
|---|---|---|
| 1 | 表現生成 | Description |
| 2 | 文脈化、グルーピング | Grouping |
| 3 | 解析オペレーター、解析モジュール | Operator |
| 4 | 解釈 | Interpretation |

「局所」という名称は概念的には近いが、位置的・空間的な意味に限定されやすい。そのため、条件や視点を与える段階として「文脈化」という名称が有力候補である。

## 3. Step 1：表現生成

### 3.1 基本思想

単一の固定的な化学表現だけで解析するのではなく、化合物を多様な表現に変換する。

目的は、特定の表現に依存せず、複数の視点からSARを観察できるようにすることである。

### 3.2 主な表現の種類

#### LBDD由来

- 物理化学記述子
- 2D descriptor
- 3D descriptor
- ECFP／Morgan fingerprint
- 部分構造指標
- スキャフォールド表現
- 薬理活性に関連する解釈可能な特徴量
- その他の高次元ベクトル表現

#### SBDD由来

- ドッキングポーズ由来の特徴量
- タンパク質残基とリガンドの相互作用
- Interaction Fingerprint
- 水素結合
- 疎水性相互作用
- π–π相互作用
- カチオン–π相互作用
- ハロゲン結合
- その他の残基・原子レベルの相互作用表現

ドッキングポーズ自体は人間が用意し、その後の特徴量化と解析を本基盤が担う想定である。

### 3.3 表現の役割

表現には少なくとも次の2つの使い方がある。

1. **グループ生成に使用する表現**
2. **生成済みグループを評価・解析する表現**

この2つは分離して考える。

たとえば、物性記述子で形成したグループをECFP空間で解析することもできる。逆に、ECFPで形成したグループをSBDD相互作用表現で評価することもできる。

---

## 4. Step 2：文脈化／グルーピング

### 4.1 目的

全データに対して単一で一貫したSARが存在するとは限らない。

むしろ、以下のような局所条件のもとでのみ関係性が見える可能性が高い。

- 特定スキャフォールドを持つ化合物群
- 特定の置換様式を共有する化合物群
- 類似した物性を持つ化合物群
- 類似した結合様式を持つ化合物群
- 類似した残基相互作用を持つ化合物群
- 高次元表現上で近い化合物群
- 構造は異なるが機能的には似ている化合物群

したがって、データ全体だけを見るのではなく、多数の異なる「文脈」を生成し、その中でSARを探索する。

### 4.2 グルーピングの種類

#### 構造ベース

- MCSベース
- スキャフォールドベース
- 部分構造ベース
- ECFP類似度ベース
- 構造クラスタリング
- 階層的構造クラスタリング

#### 非構造ベース

- 物理化学記述子によるクラスタリング
- 3D記述子によるクラスタリング
- Interaction Fingerprintによるクラスタリング
- 残基相互作用パターンによるクラスタリング
- その他の高次元表現によるクラスタリング

### 4.3 重要な設計原則

グループは、必ずしも構造的に近い化合物群ではない。

したがって、解析オペレーター側では、

- グループを何の表現で生成したか
- そのグループを何の表現で評価するか

を明確に分ける必要がある。

この考え方により、以下のような解析が可能になる。

- 物性クラスタをECFP空間で評価する
- 相互作用クラスタを構造空間で評価する
- 構造クラスタをSBDD相互作用空間で評価する
- 非構造的に形成されたグループ内で、構造活性ランドスケープを解析する

## 5. Step 3：解析オペレーター

### 5.1 役割

解析オペレーターは、個別の解析アルゴリズムを実行し、客観的なエビデンスを生成する。

重要なのは、オペレーター自身が最終解釈を行わないことである。

オペレーターは、

- 数値
- 統計量
- ランキング
- 重要特徴
- 例外
- ペア
- 局所パターン
- 信頼性指標

などを、共通スキーマで返す。

複数オペレーターの結果を比較し、意味づけし、仮説候補へ昇華する役割は、Step 4のInterpretationが担う。

### 5.2 共通出力スキーマの重要性

オペレーターを後から追加・交換可能にするため、出力形式を統一する。

共通スキーマには、少なくとも以下を含める。

- operator_name
- operator_version
- target_group_id
- grouping_representation
- evaluation_representation
- input_features
- sample_count
- result_type
- result_values
- statistical_significance
- uncertainty
- applicability_conditions
- warnings
- supporting_compounds
- supporting_pairs
- generated_evidence
- machine_readable_summary
- human_readable_summary

### 5.3 オペレーターの基本分類

#### A. グループプロファイル

各グループの基本的な性質を返す。

候補項目：

- 化合物数
- 活性分布
- 活性レンジ
- 平均値
- 中央値
- 分散
- 四分位範囲
- 高活性化合物比率
- 低活性化合物比率
- 欠損率
- 測定条件の混在
- 構造類似度分布
- ペアワイズTanimoto係数分布
- グループ内の構造多様性
- 重複化合物
- 外れ値候補

グループの「良し悪し」を直接判定するのではなく、解釈に必要な客観的情報を返す。

たとえば、

- 高活性域で狭く分布している
- 低活性域で狭く分布している
- 活性レンジが広い
- 構造類似度は低い
- 構造は多様だが活性が揃っている

といった状態を記述する。

#### B. 解釈可能特徴量と活性の関係

物性値や解釈可能な記述子について、活性との関係を評価する。

候補手法：

- Pearson相関
- Spearman相関
- Kendall相関
- Mutual Information
- 単変量回帰
- 非線形回帰
- 部分依存
- 単調性評価
- 閾値検出
- U字型／逆U字型関係
- 局所相関
- サブグループ別相関
- 特徴量間交互作用
- 多変量モデル
- SHAP
- Permutation importance

ただし、相関を因果関係として扱わない。

#### C. 特徴空間評価

ECFPなどの高次元表現は、個々の次元を直接解釈するより、空間そのものとして評価する。

候補項目：

- 近傍化合物間の活性一貫性
- k近傍における活性差
- 局所予測性
- kNN回帰性能
- 距離と活性差の関係
- 空間的自己相関
- 局所密度
- 高活性領域の集中度
- 低活性領域の集中度
- 活性境界
- 局所的不連続性
- 表現空間内の活性滑らかさ

このオペレーターは「どの特徴が効いているか」ではなく、「この表現空間がSARをどれだけ保持しているか」を評価する。

#### D. Structure–Activity Landscape

構造活性ランドスケープの起伏、滑らかさ、複雑性を評価する。

候補：

- SALI
- SARI
- Activity Cliff検出
- Activity Cliff密度
- Smooth SAR領域
- Rough SAR領域
- Neighborhood behavior
- 局所ランドスケープ粗さ
- 距離に対する活性差
- 高活性孤立点
- 異常な近傍ペア
- Cliffの再現性

SALIは特定の構造グループだけでなく、非構造表現で形成されたグループに対して、ECFPなど別の評価表現を用いて適用可能である。

#### E. 構造変換

具体的な化学変換と活性変化を解析する。

候補：

- Matched Molecular Pair
- Matched Molecular Series
- 置換基変換
- R-group変換
- コアホッピング
- 原子置換
- 環化／開環
- 官能基変換
- 変換効果の平均
- 変換効果の分布
- 変換の方向性
- 文脈依存性
- 再現性
- 例外
- 変換が有効な構造条件
- 変換が無効な構造条件

これは、最終的な構造設計提案につながりやすい重要なオペレーター群である。

#### F. SBDD相互作用

タンパク質残基との相互作用と活性の関係を解析する。

候補：

- 残基接触頻度
- 相互作用タイプ別頻度
- 残基相互作用と活性の関連
- 高活性化合物に濃縮する相互作用
- 低活性化合物に濃縮する相互作用
- 相互作用の獲得・消失と活性差
- 相互作用パターンの組合せ
- Interaction Fingerprintの局所評価
- 水媒介相互作用
- 相互作用の代替性
- 同一活性を与える異なる結合様式
- 同一結合様式でも活性が異なる例外
- 残基相互作用と構造変換の統合

## 6. 表現間解析

### 6.1 基本思想

表現生成では広く多様な特徴量を用意してよい。

ただし、表現同士の組合せをすべて総当たりすると、計算量・結果量・解釈量が爆発する。

そのため、以下の方針が望ましい。

1. 一次表現は広く生成する  
2. 類似した表現をファミリー化する  
3. 各ファミリーから代表表現を選ぶ  
4. 異なるファミリー間の組合せを優先する  
5. 必要に応じて詳細表現へ掘り下げる  

### 6.2 表現ファミリーの例

- 2D構造fingerprint
- 物理化学記述子
- 3D形状
- 薬理特徴
- 部分構造
- スキャフォールド
- Interaction Fingerprint
- 残基相互作用
- ドッキングスコア
- エネルギー
- 水和・溶媒関連
- 電子状態

### 6.3 解析マトリックス

以下の2軸で管理する。

| グループ生成表現 | 評価表現 |
|---|---|
| ECFP | 物性 |
| ECFP | Interaction Fingerprint |
| 物性 | ECFP |
| 物性 | SBDD相互作用 |
| 相互作用 | ECFP |
| 相互作用 | 3D形状 |
| スキャフォールド | 物性 |
| スキャフォールド | Interaction Fingerprint |

このマトリックスは、人間が通常は試さない表現横断的な関係を発見するための中核となる。

## 7. Step 4：Interpretation

### 7.1 役割

Interpretationは、複数オペレーターから得られたエビデンスを統合し、研究者にとって意味のある仮説候補へ変換する。

これは単なる要約ではない。

以下を行う。

- 複数エビデンスの統合
- 支持関係の確認
- 矛盾の検出
- エビデンスの独立性評価
- 仮説候補の生成
- 確信度の評価
- 代替仮説の提示
- 次に確認すべき解析の提案
- 次に合成・測定すべき化合物の方向性提示
- 人間が判断すべき論点の明示

### 7.2 LLM任せにしない

「自由に解釈してください」という指示では、以下の問題が起こりうる。

- 根拠のない一般論
- 過剰な断定
- 重要な反証の無視
- 同じ情報を複数の根拠として数える
- 人間らしいが検証不能な説明
- operator出力との不整合
- 活性向上に直結しない冗長な記述

したがって、Interpretationには明確なガイドラインと固定出力構造を与える。

### 7.3 解釈ガイドライン

#### 原則1：観察と解釈を分離する

- 観察：オペレーターから得られた事実
- 解釈：その事実が示唆する意味
- 仮説：複数の解釈から導く検証可能な説明

#### 原則2：独立した根拠を重視する

同じECFP由来の複数解析結果は、完全に独立した根拠ではない可能性がある。

たとえば、

- ECFPベースSALI
- ECFPベースActivity Cliff
- ECFP近傍解析

が同じ結論を示しても、基礎情報源は同じである。

一方、

- MMP
- 物性相関
- SBDD相互作用
- 3D形状
- 実験条件別再現性

が同じ方向を示す場合、より強い根拠となる。

#### 原則3：支持だけでなく反証を探す

各仮説について必ず以下を確認する。

- 支持するエビデンス
- 矛盾するエビデンス
- 適用外の化合物
- 例外
- 代替説明
- データ不足
- 測定誤差の可能性
- assay条件依存性

#### 原則4：因果を断定しない

相関や濃縮だけで因果関係を断定しない。

表現は以下のように段階化する。

- 観察された
- 関連が示唆された
- 仮説として考えられる
- 複数の独立エビデンスに支持される
- 実験的検証が必要

#### 原則5：適用範囲を明示する

各仮説について、どの範囲で成立しそうかを明示する。

- 特定スキャフォールドのみ
- 特定置換位置のみ
- 特定活性レンジのみ
- 特定結合様式のみ
- 特定物性範囲のみ
- 特定assay条件のみ
- データ全体に共通

#### 原則6：次の行動につなげる

解釈結果は、単なる説明で終わらせず、次の研究行動につなげる。

- 追加解析
- 再測定
- 化合物合成
- 置換基変更
- 活性クリフ周辺の探索
- 未充足相互作用の獲得
- 不要な相互作用の除去
- 物性範囲の調整
- 構造多様性の追加
- 仮説を識別する化合物設計

### 7.4 Interpretationの固定出力案

各仮説候補を、以下の形式で返す。

```yaml
hypothesis_id:
title:
target_group:
observation:
supporting_evidence:
contradicting_evidence:
evidence_independence:
alternative_explanations:
scope:
exceptions:
confidence:
confidence_rationale:
proposed_structural_implication:
recommended_next_analysis:
recommended_next_compounds:
human_review_points:
```

人間向けレポートでは、以下の順序が望ましい。

1. 注目すべき発見
2. 何が観察されたか
3. どのエビデンスが支持したか
4. どのエビデンスが矛盾したか
5. どこまで適用できるか
6. 確信度
7. 次に何を確認すべきか
8. 構造設計への示唆

## 8. オペレーターとInterpretationの役割分担

### オペレーター

- 個別解析を実行する
- 数値と事実を返す
- エビデンスを生成する
- 結果の不確実性を返す
- 適用条件を返す
- 最終判断をしない

### Interpretation

- エビデンス同士を比較する
- 独立性を評価する
- 支持と矛盾を整理する
- 仮説候補を作る
- 確信度を評価する
- 次の研究行動を提案する

当初案にあった「メタ解析オペレーター」は、独立したオペレーターとして配置するより、Interpretation側の責務とする方が役割分担が明確である。

## 10. 本基盤の独自性

本基盤の独自性は、単に多数の記述子を計算することでも、単に多数のクラスタを作ることでもない。

中核は以下である。

1. 多様な表現を生成する  
2. 多様な文脈を作る  
3. グループ生成表現と評価表現を分離する  
4. 異なる表現を横断して解析する  
5. 個別オペレーターは客観的エビデンスに徹する  
6. Interpretationが複数エビデンスを統合する  
7. 支持だけでなく矛盾と例外を扱う  
8. 仮説を次の化合物設計へ接続する  

これにより、人間が通常は選ばない視点や組合せから、局所的かつ検証可能なSAR仮説を発見することを目指す。
