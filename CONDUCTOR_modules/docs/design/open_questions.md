主 Endpoint は EC50、副次 Endpoint は WT と変異種の Fold change。**反復測定データは無い。**

```text
1. 同一化合物の重複測定があれば、その分散を直接推定
```

## F. 議論中の論点

### F-1. データの非独立性（擬似反復）【重要・方針要検討】

congeneric な社内 SAR データでは化合物が互いに強く相関しており、統計的な実効標本サイズは化合物数より大幅に小さい。独立性を仮定した検定は p 値を楽観的に見積もり、**偽陽性を量産する**。全レンズに影響する。

0.2.1 は候補を緩く取る設計のため、**偽陽性側へ振れるリスクがある**。

当初「置換検定を主軸に」と提案したが、**置換（側鎖変換）という語が誤解を招いた**ため整理し直す。ここでの「置換検定 (permutation test)」は化学的な置換基変換ではなく、**統計手法としてのラベル並べ替え**を指す。

| 案 | 内容 | 評価 |
|---|---|---|
| ラベル並べ替え検定 | 構造をブロックとして保持したまま Endpoint 値だけを並べ替えて帰無分布を作る | **推奨**。計算コストは高いが完全並列化可能 |
| 実効標本サイズの推定 | 構造類似度から相関構造を推定し自由度を割り引く | 推定が難しい |
| 骨格単位のブロック bootstrap | 骨格ごとにまとめて再抽出する | 骨格数が少ないと機能しない |

推奨案では、帰無分布側にも非独立性が同じだけ入るため相殺される。L1 で既に採用している「同サイズランダム部分集合」の考え方を全レンズへ一般化する形になる。

**要検討**: 骨格が少数で各骨格内に多数の類縁体がある場合、骨格を跨いだ並べ替えは帰無分布を過度に広げる可能性がある。骨格内並べ替えとの使い分けが要る。

### F-2. 診断モジュールのスコープ

ブランチ `0.2.1_diagnosis` に構築する計測専用モジュール。**解析ではなく計測である。** Finding を出さず、設計判断に必要な数値だけを返す。実行は1回で済ませたいため、計測項目を漏れなく洗い出す。

```text
 1. Endpoint 分布、評価系カラム間の重なり、欠測パターンと選択バイアス検定
 2. 測定ノイズ床の推定（B-0 の3手法）
 3. 構造多様性の概況（環系の種類数と分布、Murcko 骨格数、Tanimoto 分布）
 4. 各 Description 空間の局所平坦性 λ の分布              → B-1, B-2
 5. 文脈カタログの実サイズと重複度                        → B-6, B-7, D-3
 6. 変換3クラス別の pair 数（末端置換 / リンカー / 環系置換） → L2 の実行可能性
 6b. core 類似度クラス別の pair 数（exact / radius2 / radius1 / mcs_mapped）→ 類似度を緩めてどれだけ n が増えるか
 6c. 構造空間ごとの Cliff 数と、そこから変換を抽出できた割合  → Cliff 起点経路の成立性
 4b. L1a の成否（空間 × クラスタリングごとの全クラスタ λ 分布）→ L1a が実在するか、L1b 一本に絞るか
 7. 骨格ごとの R 基系列長と、骨格ペアの共通 R 基数の分布   → L7 の実行可能性
 8. 各レンズの候補数を複数の閾値で試算                    → B-4, B-5
 9. 非独立性の概況（骨格ブロックサイズ分布、実効標本サイズの目安） → F-1
10. LLM 呼出回数の実測見積もり
```

6 と 7 が今回追加された項目であり、**環構造を主軸に探索しているプロジェクトで L2 / L7 が成立するかを事前に確かめる**ためのものである。ここで環系置換ペアがほとんど取れないと分かれば、L7 の比重を上げる判断ができる。

| 項目 | 決着 |

| 実戦の症状と fixture 数値の関係 | **混同しない。** 実戦の症状は「0件」ではなく「薄い」。fixture の 0件 は小規模条件下の値であり傍証に留める |
