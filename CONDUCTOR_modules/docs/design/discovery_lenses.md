# 発見レンズ

Status: **設計協議中。未承認・未実装。**

親文書: [`../CONDUCTOR_0.2.1_specification_overview.md`](../CONDUCTOR_0.2.1_specification_overview.md)

## 0. 全レンズに共通する形式

6つのレンズは全て同じ論理形式を持つ。

```text
ある関係性 R は、Global では見えないが、条件 C のもとで現れる
```

異なるのは R が何か（変換の効果 / 空間の説明力 / 相関の符号 / 期待値 / 濃縮）と、C をどう与えるかだけである。統計的には大半が**交互作用検定**の形に帰着するため、検定基盤を共有できる。

### 0.1 「現れる」の4つの形

条件付けによって構造が現れるとき、その現れ方は4通りある。**この4つを全て検出する。**

| 形 | 内容 | 例 |
|---|---|---|
| **平均のシフト** | 条件下で効果の平均が変わる | 変換 T は文脈 C で活性を上げるが、C 外では上げない |
| **分散の縮小** | 平均は変わらないが、**ばらつきが劇的に小さくなる** | 変換 T の効果は Global では散らばるが、骨格で分けると極端に揃う |
| **符号の反転** | 条件により効果の向きが逆になる | 特徴量 F は文脈 A で正、B で負 |
| **説明力の出現** | 条件下で初めて空間が活性を説明する | 空間 S は Global では Cliff 的だが、条件 C 下では平坦 |

**分散の縮小は、初期設計から抜け落ちていた形である。** 平均のシフトだけを検定すると、「Global では効果がバラバラだが、条件を付けると一貫して同じ効果になる」という知見を取り逃がす。これは実務上きわめて有用な知見であり、かつ**平均シフト検定では検出されない**。

分散縮小は次で検出する。

```text
Var(効果 | Global) と Var(効果 | C) を比較する
帰無分布は同サイズのランダム部分集合（L1 と同じ考え方）
→ 分散比が帰無分布の下側 α 以内なら「条件下で効果が揃う」
```

平均シフトと分散縮小は**独立に起こりうる**ため、両方を検定し、どちらで検出されたかを Finding に記録する。

### 0.2 新規性はどこから来るか

**「文脈が非構造的であること」は新規性の必要条件ではない。**

新規性は次のどちらか一方からでも生じる。

| 新規性の源 | 例 |
|---|---|
| **文脈が見えない** | 非構造的クラスタで条件付けた結果、効果が現れる |
| **関係性が見えない** | 文脈は MCS クラスタ（化学者に見える）だが、その中で記述子 F が活性と相関することは見えない |

したがって、構造由来の文脈を一律に減点しない。減点するのは**関係性そのものが SAR テーブルに直接表示されるもの**に限る（例:「この骨格は活性が高い」）。

判定は「その主張が SAR テーブルを眺めて到達できるか」で行う。

| 文脈 | 関係性 | 判定 |
|---|---|---|
| 構造（MCS クラスタ） | 「活性が高い」 | `known_confirmed`。SAR テーブルで見える |
| 構造（MCS クラスタ） | 「記述子 F と活性が相関」 | **`novel`**。クラスタは見えるが相関は見えない |
| 構造（骨格） | 「変換 T の効果分散が縮む」 | **`novel`**。分散の縮小は目視できない |
| 非構造（xTB クラスタ） | 任意 | `novel`。文脈自体が見えない |

### 依存関係

```text
局所平坦性 λ（全空間・近傍単位）
   ├─ 平坦な近傍 ──→ L3（逸脱）
   │                └→ L4（未踏領域）
   └─ 鋭い Cliff ──→ L2（変換）へ材料供給

MMP canonical database
   ├─→ L2（変換 × 文脈）
   └─→ L4 の到達可能性判定

文脈カタログ（Phase 2）
   └─→ L1, L2, L5, L6 の条件 C
```

### 共通の足切り要件

各レンズのスクリーンは異なるが、次は共通とする。

- 条件 C に属する Endpoint 有効化合物数の下限を満たすこと
- 多重比較補正（BH）後の q 値が閾値以下であること
- 条件 C が翻訳可能であること（Tier 3 文脈の場合）
- 反証条件が機械的に構成できること

## L1: 条件付き平坦性

### 狙い

> 空間 A は Global では活性を説明しないが、条件 B で絞ると説明する。

CONDUCTOR の中心概念の最も直接的な表現。定義と帰無分布の設計は [`feature_space_roles.md`](feature_space_roles.md) 第3〜4章を参照。

### 2つの水準を分けて扱う 【重要】

| 水準 | 主張 | 検定の単位 | 検定数 |
|---|---|---|---|
| **L1a 空間水準** | 空間 A × クラスタリング B の**すべての**クラスタで関係性が見える | (空間, クラスタリング) | 約100 |
| **L1b クラスタ水準** | クラスタの**1個または一部**で関係性が見える | (空間, クラスタ) | 数千 |

L1a が成立するなら、**特徴量 A 自体が Endpoint 説明能力を持つ**ことを意味する。

**実データ計測により L1a は全空間で不在と確定した**（best_min_lam の最大値が負。[`calibration_results.md`](calibration_results.md) 第3章）。したがって **L1a はレンズから外し、診断指標へ降格する**。検定約100回で何も生まないものをレンズとして保持しない。

一方 **L1b は成立した**（best_max_lam の最大値が 0.8 以上）。同一の空間・同一のクラスタリングの中に λ > 0.8 のクラスタと λ < 0 のクラスタが同居しており、**「この局所でだけ関係が見える」が実データで起きている**。L1b が中心概念を担う。

両者は多重比較の負担がまったく違うため、**補正は水準ごとに独立に行う**。L1b を L1a と同じ族に混ぜない。

そして L1a の結果が L1b の解釈を変える。

| L1a | L1b | 解釈 | 扱い |
|---|---|---|---|
| 成立 | 成立 | 空間全体が良いのだから当然 | `known_confirmed` 相当。新規性は低い |
| **不成立** | **成立** | **「なぜこのクラスタだけか」** | **深堀の主要な起点。最も価値が高い** |
| 成立 | 不成立 | そのクラスタが例外 | L3（逸脱）の候補へ回す |

2行目が 0.2.1 の中心的な出力である。実データではこれが**支配的なパターン**であることが確認された。深堀では `T01`（部分集合分割）と `T03`（類似文脈への汎化）で「なぜここだけか」を掘る。

**空間ごとの重み付けは行わない。** 全6空間で λ 中央値が 0.61〜0.68 と横並びであり、空間の優劣は存在しない。多様な記述子の価値は「平坦さ」ではなく「**切り口の多様性**」にある。

### 統計形式

```text
λ(S | Global) と λ(S | C) を比較する
帰無分布は「空間 S から無作為に |C| 個抽出したときの λ」を B 回反復して構成する
```

**同サイズのランダム部分集合を帰無とすることが必須。** 小さい部分集合は何もしなくても平坦に見えるため、これを補正しないと自明な Finding を量産する。

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 空間 S の Tier | Tier 1 または 2（Tier 3 は L1 の Finding にしない） |
| 条件 C のサイズ | Endpoint 有効 N ≥ 下限 |
| 平坦性の上昇 | λ(S\|C) が帰無分布の上側 α 以内 |
| 多重比較 | BH q ≤ 閾値 |
| 翻訳 | C が Tier 3 由来なら翻訳可能であること |

### Finding の型

```text
主張      空間 S は条件 C のもとで活性を説明する
          λ(S|Global) = 0.12 → λ(S|C) = 0.68
          帰無分布（同サイズ n=42 のランダム抽出 B=1000 回）の 99.7 パーセンタイル
          BH q = 0.01
寄与       S の中で活性と関係が深い特徴量: F1 (r=0.71), F2 (r=-0.64)
文脈       C の翻訳: [Tier 1/2 の語による記述]
反証条件   C を同サイズのランダム部分集合へ置き換えたとき λ が同水準に達するなら棄却
```

### 人間に見えない理由

条件 C の候補が数百〜数千あり、人間は全ての条件で全ての空間の平坦性を確認できない。条件を試さなければ Global の Cliff 的な見え方しか得られない。

### 下流への効果

L1 が見つけた (S, C) の組は、その内部で L3（逸脱）と L4（未踏領域）を計算する土台になる。**平坦であることが保証された領域でのみ期待値の議論をする**、という規律を与える。

## L2: 変換 × 文脈の交互作用

### 狙い

> この変換の効き方は、文脈によって変わる。

化学者が SAR テーブルから到達できない知見の典型。変換そのもの（辺）は化学者が最も得意に見抜く領域だが、**効果が何によって条件付けられているか**、および**層別すると効果のばらつきが縮むか**は、目視では到達できない。

### 変換の3クラス 【重要】

標準的な MMP は非環結合の 1-cut / 2-cut に限られる。しかし**実プロジェクトでは環構造そのものを様々なパターンで試す**ことが多く、環が変われば MMP は別コアと認識するため、**標準 MMP では環の違う類縁体を比較できない**。これは L2 の適用範囲に対する致命的な制約である。

したがって変換を3クラスに拡張し、**環系の置換を一級の変換として扱う**。

| クラス | variable（交換される部分） | cut 数 | 例 |
|---|---|---|---|
| `terminal_substitution` | 末端フラグメント | 1 | −H → −F、−Me → −CF₃ |
| `linker_replacement` | 2点接続の非環部分 | 2 | −CH₂− → −O− |
| **`ring_system_replacement`** | **環系全体** | **N（環系の接続数）** | **ピリジン → ピリミジン、フェニル → チオフェン** |

#### 環系置換の定義

```text
1. 分子の環系を同定する（縮環・スピロは一つの環系として扱う）
2. その環系と分子の残りを繋ぐ結合を全て切断する
3. 環系 = variable、残り = constant（N 個の attachment point を持つ）
4. constant が一致し variable の環系が異なる2分子 = 環系置換ペア
```

**環結合そのものは切断しない。** 切断するのは環系から外へ出る結合（exocyclic bond）だけである。ビアリール結合のような環同士を繋ぐ結合は非環結合なので切断してよい。したがって「環を開く」ことはせず、構造的な妥当性は保たれる。

#### cut 数を 2 に固定しない

環系の接続数 N は 1, 2, 3, ... と変わる。末端の環なら N=1、中央の環なら N=2 以上になる。したがって **cut 数は環系の接続数から決まるものとし、上限 2 という制約を外す**。

N ≥ 3 の場合は attachment point の対応付けが難しくなるため、次で扱う。

- constant 側が複数フラグメントに分かれる場合、**canonical な順序**で整列して保持する
- attachment point の対応は一意性を要求し、対称等価な場合のみ許容する
- 対応が曖昧な場合は `ambiguous` として標準表示しない

#### 3クラスを混ぜない

件数、統計、Finding、表示を分離する。「変換」と一括りにすると、末端 F 導入と環系まるごとの交換が同じ土俵で比較されてしまう。

### Cliff 起点の変換発見 【重要】

変換の候補空間は巨大である。どこから手を付けるかを決める必要があり、**Cliff がその起点になる**。

Cliff（構造が近いのに Endpoint が大きく違うペア）は、**Endpoint を大きく動かしている構造要因が確実に存在する場所**である。化学者が実際にやっているのもこれで、似た化合物を並べて何が効いているかを探る作業は暗黙の MMP 解析にあたる。

```text
1. 構造空間の近傍から Cliff ペアを検出する（非構造空間では列挙しない）
2. 各 Cliff ペアからの変換抽出を試みる（末端置換 / リンカー置換 / 環系置換）
3. 抽出できたものだけを候補として、L2 の通常の検定へ投入する
4. 他のペアでも同方向の効果が再現すれば Finding、しなければ棄却
```

**Cliff を列挙するのは構造空間だけである。** 非構造空間の Cliff は「性質は近いが活性が違う」という事実しか与えず、**何を変えればよいかを言えない**（変換にならず、他へ適用もできない）。さらにその非構造空間が全体として Cliff 的なら、個々の Cliff は例外ですらなく常態である。詳細は [`feature_space_roles.md`](feature_space_roles.md) 3.4〜3.6。

最終判定は分類ではなく操作的基準による。**変換が抽出できたペアだけが材料になる。** 構造空間でもたまたま構造の離れたペアが近接して見えた場合は、抽出に失敗して自然に落ちる。

### Cliff が多すぎる場合の優先順位

congeneric なプロジェクトデータでは、構造空間の λ は全体的に低くなる（似た化合物が多く、活性は幅広く散る）。したがって Cliff は大量に出る。**λ が低いこと自体は構造空間では異常ではない。**

優先順位を付ける。

```text
優先度 = Endpoint 差の大きさ × 構造的近さ × 抽出された変換の他ペアでの出現数
```

第3項が最も重要である。**抽出した変換が他の多数のペアにも現れるなら強い手掛かり**であり、1組しか現れない Cliff はノイズの可能性が高い。これは「Cliff は種であり、検証は別の母集団で行う」という原則の具体化でもある。

**発見の起点と検証の母集団を分けることが要点である。** Cliff ペア自体を知見として主張しない。1ペアの活性差は測定誤差に丸ごと晒されるためである。Cliff は「この変換を調べる価値がある」という**優先順位の情報**として使い、効果の検定は変換が現れる全ペアで行う。

これにより次の両立が得られる。

| | 得られるもの |
|---|---|
| Cliff を起点にする | 効果の大きい変換へ計算資源を集中できる。化学者の直感と同じ経路 |
| 検定を全ペアで行う | 単一ペアのノイズに引きずられない |

Cliff 起点は、変換を網羅列挙する経路と**並行して**走らせる。網羅列挙だけでは effect size の大きい変換が埋もれ、Cliff 起点だけでは効果の小さい一貫した変換を取り逃がす。

### Core 類似度を文脈として扱う 【0.1.11 からの継承】

0.1.11 は Exact core だけでなく、**Attachment 制約付き MCS と Tanimoto 類似度による Similar core** を算出し、「類似 core 上で同じ変換を比較する」経路を持っていた。この機構は 0.2.1 でもそのまま使う。

ただし**出力の仕方を変える**。0.1.11 は類似 core の Evidence を並べて人間に解釈を委ねており、これが認知負荷の主因になっていた（Target 1件あたり canonical evidence 3,060行、HTML 埋め込み 500行）。

0.2.1 では **core 類似度クラスを文脈 C の一種として扱い、L2 の交互作用機構にそのまま乗せる**。人間が受け取るのは Evidence の山ではなく結論である。

```text
Core 類似度クラス（条件 C として使う）:
  exact          Exact core 一致
  radius2        Radius-2 Environment 一致
  radius1        Radius-1 Environment 一致
  mcs_mapped     Attachment 制約付き MCS で対応付け可能（Environment 不一致）

変換 T について、類似度クラスを緩めながら効果を追跡する:
  exact のみ        効果 e_exact  (n_exact)
  radius2 まで      効果 e_r2     (n_r2)
  mcs_mapped まで   効果 e_mcs    (n_mcs)
```

判定は2通りに分かれ、**どちらも Finding になる**。

| 観測 | 解釈 | 行動 |
|---|---|---|
| 類似度クラスを跨いで効果が一定 | 変換 T は core に依存しない**汎用変換** | 適用先が広い。n が増えるため証拠も強くなる |
| 類似度を緩めると効果が消える／分散が増える | 変換 T は**特定 core に固有** | 適用先は限定的だが、その core 上では強い |

これは L2 の統計形式（平均シフト／分散縮小の交互作用検定）に**そのまま乗る**。core 類似度クラスは順序を持つ文脈なので、単調性の検定（`T02`）とも相性がよい。

**機構は 0.1.11 のものを流用し、判断を機械側へ移す。** これが認知負荷への回答である。

### 環系置換だけでは足りない

環系置換ペアが成立するのは「環**以外**が完全一致する」場合に限られる。実際には環を変えると同時に側鎖も少し変わることが多く、厳密一致ペアは思ったほど取れない可能性がある。

この不足を埋める機構が**3層**ある。

| 機構 | 単位 | 問い |
|---|---|---|
| 環系置換（本節） | ペア（厳密一致） | 環を変えると活性はどう変わるか |
| **Core 類似度（上節）** | **ペア（類似 core 間）** | **同じ置換は類似 core を跨いで転写するか** |
| L7 骨格 × 置換基 | 系列 | 骨格間で置換基の序列は転写するか |

中段が 0.1.11 から継承する機構であり、厳密一致（狭い）と系列比較（粗い）の**中間の粒度**を埋める。Attachment 制約付き MCS はピリジン／ピリミジンのような環バリアント間でも対応を取れるため、**環構造探索の比較にも効く**。

3層は目的が異なるため、統合せず並行して走らせる。

### 分析単位は2つある 【実データ計測による設計変更】

当初は「変換 A→B」を唯一の分析単位としていた。**実データでこれは成立しないと判明した。**

| クラス | pairs | 異なる変換 | 3ペア以上の変換 | 1変換あたり |
|---|---|---|---|---|
| TERM | 9,548 | 7,300 | **252** | 1.31 |
| RING | 1,579 | 1,434 | **14** | 1.10 |
| LINK | 436 | 292 | **12** | 1.49 |

交互作用検定は1変換について文脈内 ≥3 かつ文脈外 ≥3、最低6ペアを要する。平均 1.1〜1.5 ペアでは大半の変換が検定不能である。

**しかしフラグメント自体は多数の文脈に繰り返し現れる。** したがって分析単位を2つ持つ。

| 単位 | 問い | 適用範囲 |
|---|---|---|
| **L2a 変換単位** | 変換 A→B の効果は文脈で変わるか | 繰り返しのある変換のみ（TERM 252 / RING 14 / LINK 12 件） |
| **L2b フラグメント寄与** | フラグメント F の寄与は文脈で変わるか | **繰り返しを要求しない。主力** |

#### L2b: フラグメント寄与（Free-Wilson 分解）

各文脈（同一 constant key = 系列）の平均からの偏差としてフラグメント寄与を推定し、F が現れる全文脈で集約する。ペアの繰り返しを要求しない。

```text
系列 s における化合物 i の Endpoint   y_si
系列平均                             ȳ_s
フラグメント F の寄与  contrib(F) = mean over s of (y_si − ȳ_s)   where frag(i) = F

条件付け:
  contrib(F | 文脈タイプ A) と contrib(F | 文脈タイプ B) を比較する
  → 差が有意なら「F の効き方は文脈で変わる」
```

これは古典的な **Free-Wilson 分解**であり、**環の比較にもそのまま適用できる**。環系置換の変換は 1,434 種類に散って検定不能だが、**環そのものは多数の文脈に現れる**ため「環 X は環 Y より良いか」は文脈横断で集約できる。

系列平均を引く操作が骨格主効果を除去するため、**骨格交絡の制御を兼ねる**。並べ替えも系列内で行う（[`calibration_results.md`](calibration_results.md) 第7章）。

#### データ構造への適合

```text
系列数（R 基2個以上）  693
系列長 最大            55
系列長 ≥5              48
```

ペアは少数の深い系列に集中している。最深系列だけで C(55,2) = 1,485 ペアを生み、TERM 全体の 15% を占める。**解析の重心はこの深い系列群に置く。**

### 統計形式（L2a 変換単位）

MMP canonical database から、変換 T の signed delta を取る。文脈 C への所属で層別し、交互作用を検定する。

```text
T の効果 in C     : median Δ, 分散, 方向一致率, n
T の効果 not in C : median Δ, 分散, 方向一致率, n

検定は2種類を並行して行う:
  平均シフト   効果の中央値の差（交互作用検定、BH 補正）
  分散縮小     Var(Δ|C) / Var(Δ|Global) が同サイズ帰無分布の下側 α 以内か
```

方向は固定構造方向の signed delta を用い、Favorable 方向へ一律反転しない（0.1.11 の設計を踏襲）。

### 分散縮小の検出（重要）

**「Global では効果がバラバラだが、構造で分けると変換の分散が極端に小さくなる」は、平均シフト検定では検出されない。**

同じ変換 A→B が、ある骨格では +0.8、別の骨格では −0.7 という具合に散らばっているとする。Global の平均は 0 付近になり、平均シフト検定は何も見つけない。しかし骨格で層別すると、各層内では効果が極端に揃う。これは**変換の効果が骨格に強く依存する**という、実務的にきわめて有用な知見である。

分散縮小は独立に検定し、Finding には検出形式（`mean_shift` / `variance_reduction` / 両方）を記録する。

### 許容性（tolerance）の検出

効果が 0 付近に集中し、**かつ分散が小さい**変換は「その位置を変えても活性が変わらない」ことを意味する。これは捨てずに `tolerance` ラベルで保持する。

```text
許容性あり  |median Δ| < 閾値  かつ  Var(Δ|C) が小さい
判定不能    |median Δ| < 閾値  だが  Var(Δ|C) が大きい（ノイズと区別できない）
```

**平均が 0 であることではなく、分散が小さいことが判定基準である。** 漫然と「変化なし」を報告すると測定ノイズを知見として主張することになるため、一貫性を要求する。

許容性は単一 Endpoint モードでは `actionability` が低いが、「この位置は触っても活性を損なわない」という設計指針になり、MPO 拡張時に価値が跳ね上がる。詳細は [`endpoint_model.md`](endpoint_model.md) 第6章。

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 対象変換 | 3ペア以上を持つ変換のみ（TERM 252件 / RING 14件 / LINK 12件） |
| 文脈内の pair 数 | n_in ≥ 下限（初期案 3） |
| 文脈外の pair 数 | n_out ≥ 下限（初期案 3） |
| 方向一致 | 文脈内の方向一致率が閾値以上 |
| 交互作用 | BH q ≤ 閾値 |
| 翻訳 | C が翻訳可能であること |

いずれかの検定（平均シフト / 分散縮小）を通過すれば候補とする。**文脈が構造由来であっても減点しない**（0.2 節）。構造クラスタで層別したときに変換の効果分散が縮むことは、SAR テーブルを眺めて到達できる知見ではない。

### Finding の型

```text
主張      変換 [From → To] は文脈 C に属する化合物でのみ活性を上げる
          C 内  : 中央値 +0.62 log (n=7, 方向一致 7/7)
          C 外  : 中央値 +0.03 log (n=11, 方向一致 5/11)
          交互作用 BH q = 0.04
文脈       C の翻訳: [Tier 1/2 の語]
          構造分類との関係: Murcko 骨格では3種類に分かれる（構造では見えない群）
自明性     ΔlogP +0.9。脂溶性で調整後も +0.48 log 残る
次の一手   C に属し、この変換が未適用の化合物: CPD-0231 (8.6), CPD-0447 (8.4)
反証条件   C 内外の効果差が、文脈をランダム置換したときの差の分布に収まるなら棄却
```

### 流用資産

0.1.11 の MMP canonical database（Target 非依存・immutable）と Evidence quality 判定機構をそのまま土台にできる。**Target 起点ではなく変換起点で走査する点が 0.1.x との決定的な違い**である。Top-1 Target の周辺を見るのではなく、全変換 × 全文脈を総当たりする。

## L3: 局所期待からの逸脱

### 狙い

> この化合物は、周りから期待されるより明らかに活性が高い。なぜか。

### 統計形式

```text
平坦な近傍 N(c, S, k) に限り（λ ≥ 閾値）
  期待値  = 近傍からの予測
  逸脱    r(c, S) = Endpoint(c) - 予測(c | N)
  標準化  z(c, S) = r / 近傍内の予測誤差の標準偏差
```

λ の計算に c を関与させないことで、逸脱検出との循環を避ける（[`feature_space_roles.md`](feature_space_roles.md) 3.2）。

### 複数空間での一致が本質

**単一空間だけで外れ値なら、その空間の作り方の問題かもしれない。複数の独立な空間で同時に外れ値になる化合物は本物である。**

18種の Description を持つことの正しい使い道がここにある。多様な表現を持つこと自体が、頑健性の検証装置になる。

```text
consensus(c) = |{ S : λ(c,S) ≥ 閾値 かつ |z(c,S)| ≥ 閾値 }|
```

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 近傍の平坦性 | λ(c, S) ≥ 閾値（この空間で期待値を語ってよいか） |
| 近傍サイズ | 有効な近傍が k 個確保できること |
| 逸脱の大きさ | \|z(c, S)\| ≥ 閾値 |
| 空間横断の一致 | consensus(c) ≥ 2（独立な2空間以上で逸脱） |

### 新規性ラベル

逸脱が**構造空間でも見えるか、非構造空間でしか見えないか**を判定し、ラベルする。

- 非構造空間でのみ逸脱 → `novel`（化学者の構造近傍では見えない）
- 構造空間でも逸脱 → `known_confirmed`（化学者が「この化合物は変だ」と既に感じている可能性）

両方報告する。後者は系の較正が効いていることの証明として価値がある。

### Finding の型

```text
主張      化合物 X (pIC50 8.9) は近傍から上方に逸脱する
          D019 空間: 近傍10化合物の中央値 7.4、z = +3.1
          D016 空間: 近傍10化合物の中央値 7.6、z = +2.7
          consensus = 2 空間
文脈       両空間とも近傍平坦性 λ ≥ 閾値（期待値を語ってよい近傍）
差分       X と近傍の差: [Tier 1/2 の語による記述]
新規性     構造空間（D002）では逸脱しない → novel
反証条件   近傍サイズ k を変えたとき、または近傍から X を除いて再計算したとき
          z が閾値を下回るなら棄却
```

### SALI との関係

SALI の直感（構造は似ているのに活性が違う）は正しいが、**ペア単位という定式化がノイズに脆い**。1ペアの活性差は測定誤差に丸ごと晒される。

L3 は同じ直感を**近傍集合**で取るため、k 個の平均により誤差が概ね 1/√k に落ちる。SALI を無理に使うのではなく、**SALI がやりたかったことのノイズ頑健版**として吸収する。

## L4: 未踏の有望領域

### 狙い

> 誰もここを作っていない。しかし周辺の活性は高い。

### 人間に見えない理由

これが最も明確である。**SAR テーブルは存在する化合物の表であり、作られなかった分子には行が存在しない。** 人間は「無いもの」を眺めることが原理的にできない。系にしかできない仕事である。

### スコア

3つの積とする。

```text
スコア(領域 R) = 下側信頼限界(R) × 密度ギャップ(R) × 到達可能性(R)
```

| 項 | 意味 | 効果 |
|---|---|---|
| **下側信頼限界** | 近傍からの期待活性の楽観値ではなく保守値 | 近傍が少ない・ばらつく領域は自動的にスコアが下がる |
| **密度ギャップ** | 領域内の既存化合物の少なさ | 本当に未踏かを担保 |
| **到達可能性** | R へ到達する既知の変換パスが MMP DB に存在するか | 行動可能性を担保 |

**到達可能性が最も重要な項である。** これが無いと「空いている点」を報告するだけの、抽象的で行動に繋がらない話になる。到達可能性を掛けることで、L4 は L2 の変換データベースに依存する設計となり、「この空白は、この化合物にこの変換を当てれば届く」という具体的な次の一手まで一括で出せる。

下側信頼限界を使うことで、判定が困難な領域は自動的に順位の下位へ沈む。有望性の判断を人間の目視に頼らず統計量へ埋め込む。

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 領域の平坦性 | 近傍の λ ≥ 閾値（外挿してよい領域か） |
| 密度 | 領域内の既存化合物数 ≤ 上限 |
| 期待活性 | 下側信頼限界 ≥ 閾値 |
| 到達可能性 | 既知変換による到達パスが1本以上存在 |

### Finding の型

```text
主張      領域 R は未踏だが有望である
          近傍活性 中央値 8.2 / 下側信頼限界 7.6
          領域内の既存化合物 2個（密度ギャップ大）
領域の記述 [Tier 1/2 の語による記述]
最近接     CPD-0118 (8.5), CPD-0342 (8.1)
到達経路   CPD-0118 に変換 [From → To] を適用すると R に入る
          この変換は文脈 C で n=6, 方向一致 5/6 の実績（L2 Finding #7 と関連）
反証条件   到達経路で生成される構造が Run 内既存化合物と一致する、または
          RDKit で構築不能なら棄却
```

## L5: 文脈間の符号矛盾

### 狙い

> 特徴量 F は、文脈 A では活性を上げ、文脈 B では下げる。

### 統計形式

L2 と同じ交互作用の形だが、効果の単位が「変換」ではなく「任意の特徴量」である点が異なる。検定基盤を共有できる。

```text
文脈 A における corr(F, Endpoint)
文脈 B における corr(F, Endpoint)
Fisher z 変換による差の検定、BH 補正
```

### Global で消えることの証明力

**符号が逆の2群を混ぜると相関はゼロになる。** したがってこの種の関係は Global 解析では原理的に見つからない。

Finding にこれを明記する。「Global では r = 0.04 だった」という一行が、**なぜこれまで誰も気づかなかったか**の説明として機能し、知見としての説得力を高める。

0.1.x の A003 が 0/868 だったことの裏返しでもある。Global 相関も局所相関も計算していたが、**その差が意味を持つ場合を検定していなかった。**

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 特徴量 F の Tier | Tier 1 または 2 |
| 各文脈のサイズ | 両文脈とも Endpoint 有効 N ≥ 下限 |
| 相関の大きさ | 両文脈とも \|r\| ≥ 閾値 |
| 符号 | 逆であること |
| 交互作用 | Fisher z 差の BH q ≤ 閾値 |

### Finding の型

```text
主張      特徴量 F の活性への効き方は文脈により逆転する
          文脈 A: r = +0.61 (n=40)
          文脈 B: r = -0.52 (n=35)
          Fisher z 差の BH q = 0.02
          Global: r = +0.04 → 打ち消し合って見えていなかった
文脈       A の翻訳 / B の翻訳: [Tier 1/2 の語]
          A と B の違い: [記述]
自明性     F はサイズ・脂溶性と独立か
次の一手   文脈 A では F を上げ、文脈 B では下げる方向で設計する
反証条件   文脈ラベルをランダム置換したとき同等の符号逆転が生じるなら棄却
```

## L6: 活性濃縮クラスタ

### 狙い

> このクラスタは活性が濃縮している。

0.1.x の FF ≥ 0.50 選抜に相当する。**捨てない。ただし6つある入口の1つへ格下げする。**

0.1.x での問題は FF 濃縮という視点が間違っていたことではなく、**それが唯一の入口であり、かつ下流の全解析を事前に絞っていたこと**である。

### 0.1.x との決定的な違い

> **L6 の結果を他レンズの入力フィルタに使ってはならない。**

L6 は Finding を直接生成する。L1〜L5 は L6 の結果に依存せず、全化合物・全文脈に対して独立に走る。これにより循環と範囲制限が構造的に発生しなくなる。

### 統計形式

```text
クラスタ内の Favorable 比率 vs Global の Favorable 比率
Fisher 正確検定、オッズ比、BH 補正
```

Favorable の定義（Global Endpoint の上位20%）は踏襲するが、**この定義は L6 の内部にのみ閉じる**。他レンズは Endpoint を連続値として扱い、二値化しない。

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| クラスタサイズ | Endpoint 有効 N ≥ 下限 |
| 濃縮 | FF ≥ 閾値 |
| 有意性 | Fisher BH q ≤ 閾値 |
| 翻訳 | クラスタが翻訳可能であること |

### Finding の型

```text
主張      クラスタ K は活性が濃縮している
          K 内 FF = 0.68 (N=31) vs Global FF = 0.20
          オッズ比 8.4、Fisher BH q = 0.0003
文脈       K の翻訳: [Tier 1/2 の語]
          構造分類との関係: [Murcko と一致するか]
反証条件   クラスタラベルをランダム置換したとき同等の濃縮が生じるなら棄却
```

### 実行可能性の限界（正直な評価）

L6 の Finding は**それ自体では「次に何を作るか」を示さない**。「活性が高い化合物の集まりがあります」は解析の入口で分かることであり、結論ではない。

したがって L6 の Finding は、スコアリング（段階B）の**実行可能性の軸で低い値を取る**。これは仕様であって欠陥ではない。L6 の主たる価値は:

1. 系の較正の確認（既知の良い系列が検出されるか）
2. 他レンズの Finding を解釈する際の文脈提供
3. 翻訳された記述による「なぜこの群が良いのか」の言語化

## L7: 骨格 × 置換基の交互作用（SAR の転写性）

### 狙い

> 骨格 A で効いた置換基は、骨格 B でも効くのか。

複数の環構造を並行して試すプロジェクトにおける中心的な問いである。L2 が**ペア単位**で厳密一致を要求するのに対し、L7 は**系列単位**で比較するため、骨格以外が完全一致していなくても成立する。

### 統計形式

骨格（環系）ごとに R 基系列を作り、共通 R 基を持つ骨格ペアを比較する。

```text
骨格 A の系列: R1, R2, ..., Rm に対する Endpoint
骨格 B の系列: R1, R2, ..., Rm に対する Endpoint
（共通 R 基が m 個以上あるペアだけを対象とする）

二元配置の分解:
  骨格の主効果     骨格 B は骨格 A より平均 +Δ（全 R 基に共通のオフセット）
  R 基の主効果     R 基の序列（両骨格に共通する傾向）
  交互作用         骨格 × R 基（序列が骨格によって変わる）

転写性の指標:
  共通 R 基上での Spearman 順位相関 ρ
```

### 3つの Finding 型

| ρ と主効果 | 解釈 | 行動 |
|---|---|---|
| ρ 高い かつ 主効果あり | **骨格 B は A の上位互換**。R 基の効き方は同じで、底上げされている | 骨格を乗り換える。R 基の再探索は不要 |
| **ρ 低い / 負** | **SAR が骨格依存**。骨格と R 基の組合せが効いている | 未試験の組合せに機会がある。L4 と接続 |
| ρ 高い かつ 主効果なし | **R 基の効果は骨格に依らない** | 骨格と R 基を独立に最適化できる。探索空間が積から和へ落ちる |

3番目は一見地味だが実務価値が高い。**探索を分解してよいという保証**は、試作数を大きく削減する。

2番目が最も「注目に値する」型である。骨格ごとに R 基の序列が変わるなら、**試していない組合せに上位候補が眠っている**。

### 段階Aスクリーン

| 項目 | 条件 |
|---|---|
| 骨格あたりの系列長 | 各骨格で Endpoint 有効な R 基が下限以上 |
| 共通 R 基数 | 骨格ペア間で共通する R 基が m 個以上 |
| 交互作用 | 二元配置の交互作用項が BH q ≤ 閾値 |
| または転写性 | ρ が閾値以下（序列の逆転） |

骨格ペアの列挙は、**共通 R 基数が下限を満たすペアだけ**に限る。これにより組合せは実質的に抑えられる。

### Finding の型

```text
主張      骨格 P と骨格 Q で置換基 SAR の序列が逆転する
          共通 R 基 8 個、Spearman ρ = −0.62
          交互作用 BH q = 0.01
          骨格の主効果: Q は P より平均 +0.3（有意でない）
序列       P: R3 > R1 > R5 > ...
          Q: R5 > R1 > R3 > ...
次の一手   骨格 Q × R2 / R7 は未試験。P では R2 が上位のため Q では下位と予測されるが、
          R7 は P で下位のため Q での上位が期待される
反証条件   R 基ラベルを骨格内で置換したとき同等の序列逆転が生じるなら棄却
```

### 人間に見えない理由

個々の SAR テーブルは化学者が読める。しかし **骨格ペアの総当たりで序列相関を比較する**ことは、骨格数が増えると人手では現実的でない。骨格が 10 なら 45 ペア、20 なら 190 ペアある。

さらに、**「序列が転写する／しない」はテーブルを並べても直感的に見えない**。順位相関という量に落として初めて比較できる。

### L2 との関係

| | L2 環系置換 | L7 骨格 × 置換基 |
|---|---|---|
| 単位 | ペア（厳密一致） | 系列（共通 R 基） |
| 要求 | 環以外が完全一致 | 共通 R 基が m 個以上 |
| 出力 | 「この環をこの環に変えると上がる」 | 「この骨格では序列が違う」 |
| 被覆 | 厳密一致が取れる範囲のみ | 広い |

**両方必要である。** L2 は精密だが被覆が狭く、L7 は被覆が広いが粒度が粗い。
