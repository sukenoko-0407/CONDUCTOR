# 特徴量空間の役割と条件付き平坦性

Status: **設計協議中。未承認・未実装。**

親文書: [`../CONDUCTOR_0.2.1_specification_overview.md`](../CONDUCTOR_0.2.1_specification_overview.md)

## 1. 二つの役割

特徴量空間は CONDUCTOR の中で二つの異なる仕事をする。この二つは**要求される性質が違う**ため、分離して扱う。

| 役割 | 何をするか | 要求される性質 | 使える空間 |
|---|---|---|---|
| **文脈定義** | 化合物を再現性のある群へ分ける | 群が安定して再現されること | 全空間 |
| **説明** | なぜそうなるかを人間へ伝える | 人間が読んで意味が取れること | 解釈可能空間のみ |

分離の理由は単純である。Fingerprint 空間で条件付き平坦性が見つかったとして、「`morgan_bit_1417` が効いています」と提示されても人間には使えない。しかし**群を定義する道具としては Fingerprint は有効**であり、むしろ構造以外の切り口を与える点で価値がある。

> **規則**: すべての Finding は、解釈可能な説明成分を最低1つ持たねばならない。

## 2. 解釈可能性の階層

二値ではなく3段階で扱う。

| Tier | 定義 | 該当空間の例 | 説明への使用 |
|---|---|---|---|
| **Tier 1** 直接解釈可能 | 特徴量名を読めば化学者が意味を理解できる | RDKit 2D 記述子、RDKit fragment counts、基本物性（MW, logP, TPSA, HBD/HBA, 回転結合数, 芳香環数） | 可。**優先** |
| **Tier 2** 注釈付きで解釈可能 | 意味は定まっているが、化学者へ一言の注釈が要る | Mordred 2D/3D、RDKit 3D、3D shape（慣性・球状性）、USR/USRCAT、xTB 量子記述子、MACCS keys（各 key は定義済み部分構造） | 可。注釈を併記する |
| **Tier 3** 非解釈 | 個々の次元に人間が読める意味が無い | Morgan/ECFP bit、atom-pair、topological torsion、path/pattern/layered FP、Avalon、Gobbi Pharm2D、ChemBERTa embedding | **不可**。文脈定義にのみ使う |

Tier 3 の空間は **文脈を定義する側でだけ使う**。そこで見つかった知見は、報告前に Tier 1/2 の語へ翻訳する（第5章）。

### 2.1 Tier 2 の注釈文

Tier 2 の特徴量は、Finding へ表示する際に**必ず注釈を併記する**。注釈は Capability 側に固定文として持たせ、Run ごとに生成しない。

| 空間 | 注釈文 |
|---|---|
| Mordred 2D | 結合表から計算される広範な2D記述子群。トポロジー指数、自己相関、電荷分布の要約などを含む。3D 構造を必要としない |
| Mordred 3D | 立体配座に依存する3D記述子群。分子の広がり、表面積、慣性に関する量を含む。配座生成の結果に依存する |
| RDKit 3D | 分子の形状指標。慣性モーメント比（PMI）、非球形度、偏心度など。配座生成の結果に依存する |
| 3D shape | 分子の全体形状を表す少数の指標。球状性・棒状性・円盤状性の度合い |
| USR / USRCAT | 分子形状を、いくつかの参照点からの原子距離分布として表現した記述子。USRCAT は薬理作用点の型（疎水性・水素結合供与/受容など）も区別する |
| xTB 量子記述子 | 半経験的量子化学計算 (GFN2-xTB) による電子的性質。HOMO/LUMO エネルギー、双極子モーメント、原子部分電荷などを含む |
| MACCS keys | 166 個の定義済み部分構造それぞれの有無。各キーは特定の官能基や構造パターンに対応するため、個別キーは解釈できる |

注釈の役割は「その特徴量が何を見ているか」を一文で伝えることであり、数値の解釈方法までは述べない。数値の意味は Finding 本文が担う。

## 3. 局所平坦性

### 3.1 なぜ空間単位ではなく近傍単位か

ある特徴量空間が全体として Cliff だらけでも、その中に局所的に滑らかな領域が埋まっていることは普通にある。空間単位で足切りすると、その滑らかな部分まで一緒に捨ててしまう。

逆に、全体は滑らかな空間でも、局所的に鋭い Cliff が数か所あるのは自然なことであり、それは捨てるのではなく**別のレンズの材料に回すべき**である。

したがって平坦性は**近傍単位**で判定し、結果を振り分ける。

```text
各 (化合物 c, 空間 S) について局所平坦性 λ(c, S) を計算
  λ が高い（平坦）  → L3（局所期待からの逸脱）と L4（未踏領域）の土台に使える
  λ が低い（Cliff） → 期待値という概念が無効。個別の鋭いペアを L2 の材料へ回す
```

### 3.2 定義

平坦性は「近傍の内部で、互いの活性をどれだけ予測し合えるか」で測る。

```text
N(c, S, k) = 空間 S における c の k 近傍（c 自身を含まない）

λ(c, S) = 1 - ( N 内部の leave-one-out 予測誤差 / Global Endpoint の分散 )
```

**c 自身を λ の計算へ関与させない**のが要点である。関与させると、c が外れ値である場合に c 自身が近傍を非平坦に見せ、L3 の逸脱検出と循環する。近傍の内部整合性（λ）と、その近傍に対する c の逸脱（L3 の残差）を、計算上完全に分離する。

```text
λ = 近傍の性質（c は関与しない）
r(c) = |Endpoint(c) - 予測(c | N)|   ← c の性質
```

### 3.3 平坦と Cliff は両方に価値がある 【重要】

> **平坦であることがすべてではない。Cliff にこそ大きな情報が眠っている。**

λ は空間を捨てるための道具ではなく、**二分して別の経路へ振り分けるための道具**である。どちらの側にも固有の価値がある。

| λ | 意味 | 何ができるか | 行き先 |
|---|---|---|---|
| 高い（平坦） | 近傍が互いの活性を予測できる | **期待値が語れる** | L1（説明力）、L3（逸脱）、L4（未踏領域） |
| 低い（Cliff） | 構造が近いのに活性が大きく違う | **情報が濃い。構造要因を特定できる** | L2（MMP・変換解析） |

Cliff は、化学者が実際に行っている作業そのものである。**構造の似た化合物同士を比べ、Endpoint を大きく動かしている構造要因（特に置換基）を探る。** これは暗黙の MMP 解析であり、Cliff はその入口にあたる。

したがって λ が低い近傍を「使えない空間」として捨ててはならない。**MMP 経路へ送る。**

### 3.4 Cliff は構造空間でのみ列挙する 【重要】

**Cliff が情報を持つのは、「近い」が抽出可能な差分を意味するときだけである。**

| 空間 | 「近い」の意味 | 差分を抽出できるか |
|---|---|---|
| **構造空間** | 部分構造を共有している | **できる。**「Cl → OMe」と名指せ、他の化合物へ適用できる |
| **非構造空間** | 計算された性質の値が近い | **できない。** 構造は全く違いうる |

非構造空間の Cliff から得られるのは「この2化合物は性質が近いのに活性が違う」という事実だけであり、**何を変えればよいかを言えない**。変換にならず、他へ適用もできない。

さらに、**その非構造空間が全体として Cliff 的である場合、個々の Cliff は例外ですらない**。それがその空間の常態であり、例外でないものに情報は無い。これは L3（逸脱）で「平坦な近傍でのみ期待値を語る」とした規律と同じ論理であり、Cliff 側にも同じ規律を適用する。

技術的な問題も重なる。高次元記述子空間では距離集中により最近傍が実質的に無意味になりやすく、そこで定義した Cliff は二重に信頼できない。

> **規則: Cliff の列挙は構造空間に対してのみ行う。非構造空間では Cliff を列挙しない。**

非構造空間の λ が低いことは「**その空間はそこでは活性を説明しない**」という情報であり、L1／L3／L4 のゲートとしてのみ使う。個別の Cliff へ降りない。

### 3.5 構造性は解釈可能性とは独立の軸である

空間には直交する2つの軸がある。混同しない。

| 軸 | 問い | 用途 |
|---|---|---|
| **解釈可能性**（Tier 1/2/3） | 人間が読んで意味が取れるか | **説明**に使えるか |
| **構造性**（structural / non-structural） | 近さが抽出可能な構造差分を意味するか | **Cliff 抽出**に使えるか |

```text
ECFP4 (D002)        Tier 3（説明不可）だが 構造空間（Cliff 抽出可）
RDKit 2D (D001)     Tier 1（説明可）  だが 非構造空間（Cliff 抽出不可）
```

構造空間に分類するのは、**部分構造の有無を符号化する fingerprint 群**である。

| 構造空間 | Morgan/ECFP、MACCS、atom-pair、topological torsion、RDKit path/pattern/layered、Avalon |
|---|---|
| 非構造空間 | RDKit 2D/3D 記述子、Mordred 2D/3D、3D shape、USR/USRCAT、xTB、Gobbi Pharm2D、ChemBERTa embedding |
| 判断が微妙 | RDKit fragment counts (D006)。count が近くても構造が同じとは限らないため、既定では非構造扱いとする |

### 3.6 判定は分類ではなく操作的基準で行う

上の分類は既定値であり、最終判定は**操作的基準**で行う。

> **Cliff が L2 の材料になる条件は「そのペアから変換が抽出できること」である。**

```text
1. 構造空間で Cliff ペアを検出する
2. 各ペアから変換の抽出を試みる（末端置換 / リンカー置換 / 環系置換）
3. 抽出できたものだけを L2 へ渡す
4. 抽出できないペア（構造が離れすぎている）は棄却し、件数だけ記録する
```

この基準は境界事例を自動的に捌く。構造空間に分類した空間でも、たまたま構造の離れたペアが近接して見えた場合は、変換が抽出できないため自然に落ちる。

### 3.7 Cliff の扱いにおける注意

ただし、単一の Cliff ペアをそのまま知見として主張しない。1ペアの活性差は測定誤差に丸ごと晒される。

Cliff は**仮説の種**として使い、検定は別の母集団で行う。

```text
1. Cliff ペアを検出する（距離が近く Endpoint 差が大きい）
2. そのペアの構造差分（変換）を抽出する
3. その変換が他のペアでも同方向の効果を持つかを検定する
4. 再現すれば Finding、再現しなければノイズとして棄却
```

**発見の起点と検証の母集団を分ける**ことで、Cliff の情報量を活かしつつノイズ耐性を得る。詳細は [`discovery_lenses.md`](discovery_lenses.md) の L2「Cliff 起点の変換発見」を参照。

0.1.x では SALI/cliff 解析が D002 (ECFP4) 限定であり、単独の Finding 生成器として使われて成果が出なかった。0.2.1 では**全空間に対して計算する共通インフラ**とし、平坦側と Cliff 側の双方へ材料を供給する。

## 4. 条件付き平坦性（L1 の土台）

### 4.1 概念

> 空間 A は Global では Cliff 的（活性を説明しない）でも、特徴量 B でフィルタすると平坦（活性を説明する）になり得る。

これが CONDUCTOR の中心概念の最も直接的な表現である。Global なデータが単純な関係性で記述できることは現実にはほぼ無い。しかし**ある局所に着目すると有用な関係性が現れる**。

```text
λ(S | Global)  低い    空間 S は全体では活性を説明しない
λ(S | C)       高い    条件 C で絞ると、空間 S は活性を滑らかに説明する
→ Finding: 「S は C のもとで活性を説明する」
```

条件 C の候補は数百〜数千あり、人間が全て試すことはできない。**機械が総当たりする。**

### 4.2 説明力には2つの水準がある 【重要】

「条件付けると関係性が見える」には、範囲の異なる2つの水準がある。**両者は主張の強さも多重比較の負担もまったく違うため、分けて扱う。**

| 水準 | 主張 | 検定の単位 | 検定数の目安 |
|---|---|---|---|
| **L1a 空間水準** | 特徴量 A × クラスタリング B が作る**すべての**クラスタで関係性が見える | (空間, クラスタリング) | 18 × 6 ≒ 100 |
| **L1b クラスタ水準** | 生成されたクラスタの**1個または一部**で関係性が見える | (空間, クラスタ) | 数千 |

**L1a が成立するなら、それは特徴量 A 自体が Endpoint 説明能力を持つことを意味する。** SALI はもともとこの水準を評価するために導入された指標である。見つかれば強力で、汎用性も高い。

しかし**実践では、そのような望ましい特徴量はなかなか見つからない**というのが 0.1.x 運用からの実測である。したがって設計の重心は L1b へ置く。

### 4.3 L1a と L1b の関係

両者は独立ではなく、**L1a の結果が L1b の解釈を変える**。

| L1a | L1b | 解釈 |
|---|---|---|
| 成立 | 成立 | 当然の帰結。**新規性は低い**（空間全体が良いのだから個別クラスタでも見えて当たり前） |
| 不成立 | 成立 | **「なぜこのクラスタだけか」という問いが立つ。** 深堀の主要な起点 |
| 成立 | 不成立 | そのクラスタが例外。逸脱の候補 |
| 不成立 | 不成立 | 何もない |

2行目が 0.2.1 の主戦場である。**L1a が成立しない空間で L1b が出ることは、その局所に固有の何かがあることを示唆する。** この「なぜここだけ」が深堀テンプレート `T01`（部分集合分割）と `T03`（類似文脈への汎化）の入口になる。

### 4.4 L1a は他レンズの重み付けにも使う

L1a が高い空間は、L3（逸脱）と L4（未踏領域）の土台としてより信頼できる。L1a を空間ごとの信頼度として保持し、下流レンズのスコアへ反映する。

### 4.5 帰無分布の設計（重要）

**小さい部分集合は何もしなくても平坦に見える。** これを補正しないと、L1 は「小さい群は平坦です」という自明で無数の Finding を量産し、0.1.x とは別の形で出力を薄くする。

したがって帰無分布は**同サイズのランダム部分集合**とする。

```text
条件 C（サイズ n）について:
  λ_observed = λ(S | C)
  帰無分布   = 同じ空間 S から無作為に n 個を抽出して λ を計算する操作を B 回反復
  有意性     = λ_observed が帰無分布の上側何パーセンタイルにあるか
```

サイズを揃えることで「小ささによる見かけの平坦性」が帰無側にも同じだけ入り、相殺される。さらに BH 補正を全条件に対して適用する。

### 4.3 条件の型と解釈可能性

条件 C は Tier を問わず使える（文脈定義の役割）。ただし Finding として報告するとき、C は Tier 1/2 の語へ翻訳されていなければならない。

空間 S 側については、**S が Tier 3 の場合は L1 の Finding として報告しない**。「ECFP4 空間は条件 C のもとで平坦です」は、平坦であること自体は真でも人間に行動を促さない。S は Tier 1/2 に限る。

| S（平坦になる空間） | C（条件） | 報告可否 |
|---|---|---|
| Tier 1/2 | Tier 1/2 | 可 |
| Tier 1/2 | Tier 3 | 可（C を翻訳した上で） |
| Tier 3 | 任意 | **L1 としては不可**。ただし L3/L4 の土台としては使える |

## 5. 文脈の翻訳

### 5.1 目的

Tier 3 空間で定義された文脈を、人間が読める語へ変換する。これができない文脈を含む Finding は報告しない。

### 5.2 手順

```text
文脈 C（例: D002 由来クラスタ C007-12、所属 34 化合物）について

1. 目的変数を「C に属するか否か」の二値とする
2. 説明変数を Tier 1 記述子（必要なら Tier 2 も）に限定する
3. 低容量の解釈可能モデル（正則化ロジスティック回帰、または浅い決定木）を当てる
4. 判別に寄与する記述子とその方向を取り出す
5. 判別精度が閾値未満なら「翻訳不能」とする
```

出力例:

```text
C007-12 の翻訳:
  判別 AUC 0.87（Tier 1 記述子のみ）
  特徴: 芳香環数 ≥ 3, TPSA 60–90, 塩基性窒素を持つ
  注意: Murcko 骨格では3種類に分かれており、構造分類では一つの群として見えない
```

最後の行が重要である。**構造分類では見えない群が、物性の語では記述できる**という事実そのものが、その文脈の価値を示す。

### 5.3 翻訳不能な場合

判別精度が閾値に満たない文脈は「Tier 1/2 の語では記述できない群」である。この場合:

- その文脈を使った Finding は**報告しない**
- ただし候補プールには理由付きで残す（`untranslatable_context`）
- 翻訳不能な文脈が多数を占める場合、それ自体が診断情報として報告される（特徴量設計の見直し材料）

翻訳を諦めて Fingerprint bit をそのまま提示することはしない。人間が使えない情報を出さない、という方針を優先する。

## 6. 未決事項

1. 局所平坦性の近傍サイズ k（固定値か、密度適応か）
2. λ の閾値（平坦とみなす水準）。実データでの分布確認が必要
3. 帰無分布の反復数 B と計算コストの釣り合い
4. 翻訳の判別精度閾値（AUC いくつを翻訳可能とするか）
5. Tier 2 の注釈文を誰がどう用意するか（Capability 側に固定文を持たせる案）
6. Mordred の一部特徴量は Tier 2 と Tier 3 の境界が曖昧。個別分類が必要か
7. 距離計量の選択（各空間の natural metric をそのまま使うか、標準化するか）

集約は [`open_questions.md`](open_questions.md)。
