# CONDUCTOR 0.2.1 診断モジュール

**計測専用です。** Finding（知見）は出しません。0.2.1 の設計判断に必要な数値だけを返します。

閾値の較正（[`../docs/design/open_questions.md`](../docs/design/open_questions.md) の B 群）は
実データ環境でしか行えないため、このモジュールで一度だけ計測し、結果を設計へ持ち帰ります。

## レポートに構造は含まれません

出力 `diagnosis_report.md` には **SMILES・compound ID・構造を一切含めません**。集計統計のみです。
社内データのまま外部へ共有できることを設計要件としています。

## 使い方

```bash
cd CONDUCTOR_modules/diagnosis

# 1. データ無しで配線を確認（合成データ・数秒）
pixi run selftest

# 2. 設定を作る
cp config.example.yaml config.yaml
#    csv_path / id_column / smiles_column / endpoints を実データに合わせて編集

# 3. 計測を実行
pixi run run
```

出力は `diagnosis_output/` に作られます。

| ファイル | 内容 |
|---|---|
| **`diagnosis_digest.txt`** | **これを書き写して渡してください。** 約50行・1,400文字 |
| `diagnosis_report.md` | 人間が読む詳細版（ファイルを渡せる場合はこちら） |
| `diagnosis_report.json` | 全数値 |
| `stages/*.json` | 段階ごとの生データ |
| `stages/*.error.txt` | 失敗した段階の traceback |

## 結果の渡し方（ファイルを持ち出せない場合）

実行の最後に、ダイジェストが**画面へそのまま表示されます**。その枠内だけを書き写してください。

- **数字と行の順序を正確に。** ラベルの表記は多少崩れても構いません
- 最終行の `[CK] xxxxxx` は数値だけから作ったチェックサムです。
  受け取り側が再計算し、**一致しなければ転記誤りが判ります**

### なぜ圧縮・ハッシュ形式にしないか

全結果を gzip+base64 で符号化すると、1,000 化合物規模では **30,000〜70,000 文字**になり、
可読ダイジェスト（約1,400文字）より**手間が 20〜50 倍**に増えます（base64 化で 4/3 倍に膨らむため）。

さらに base64 は 1 文字の誤りで復号が全滅します。可読形式なら誤りはその数値1個に留まり、
チェックサムで検出もできます。手書き転記では可読形式が有利です。

## 設定で注意する点

**評価系が変わって別カラムに分かれている場合、統合せずそれぞれ別 Endpoint として登録してください。**
重なりの有無はこのモジュールが測ります。重なりが乏しければ統合は不可能です（オフセットを推定できないため）。

`transform` は EC50/IC50 を nM で持っている場合 `neg_log10` を指定します（pEC50 へ変換）。
すでに pEC50 等へ変換済みなら `none` です。

`descriptor_set` は既定 `fast`（数分）。L1a の探索範囲を広げたい場合のみ `full`（数十分）にします。
3D / xTB / ChemBERTa は診断では計算しません（時間対効果が低いため）。

## 段階と、それが答える設計上の問い

| 段階 | 計測内容 | 答える問い |
|---|---|---|
| 1 | Endpoint 分布、カラム間の重なり、欠測パターン | 統合可能か。**選択バイアスが入っていないか** |
| 2 | 環系・Murcko 骨格・Tanimoto 分布 | L2 環系置換と L7 の成立余地。Cliff 距離下限（B-17） |
| 3 | 測定ノイズ床（3手法） | **B-0。ここが決まると B-13 / B-14 が連動する** |
| 4 | 変換3クラス別の pair 数、core 類似度緩和、Cliff 抽出率 | L2 の実行可能性。Cliff 起点経路が成立するか |
| 5 | 局所平坦性 λ、L1a / L1b の成立性 | B-1, B-2, **B-18（L1a は実在するか）** |
| 6 | L7 系列長と共通 R 基数の分布 | L7 の成立可能性（C-13 の m） |
| 7 | 級内相関と実効標本サイズ | **F-1。偽陽性リスクの大きさ** |

各段階は独立に結果を書き出すため、途中で失敗しても手前の結果は残ります。

## 特に注目する数値

- **選択バイアス**: 系統的欠測が検出されたら、その Endpoint を使う解析は範囲制限を受けます
- **ノイズ床**: 0.1.x の `mmp_neutral_tolerance = 0.1` が妥当かを決めます
- **環系置換の pair 数**: 少なければ L2 より L7 に比重を置く判断になります
- **Cliff 抽出率**: 低ければ Cliff 起点経路の設計を見直します
- **L1a（最小クラスタ λ）**: どの空間でも低ければ **L1b 一本に絞る**判断になります
- **実効標本サイズ**: 化合物数から大きく縮むなら、ブロック構造を保った並べ替え検定が必須になります

## 診断における近似

実装本体と違い、診断では次を簡略化しています。**pair 数はやや過大評価寄りです。**

- MMP の attachment point 対応付けを行わない（全 dummy を `[*]` に潰す）
- Similar core を Attachment 制約付き MCS ではなく constant fragment の Tanimoto で近似
- クラスタリングは average-linkage 凝集型の1手法のみ

実行可能性の判断には十分ですが、これらの数値を実装本体の期待値として使わないでください。
