# A009 Standard Series report

選抜Cluster一覧をDescription、Clustering、N、FF、odds ratio、p/q、Series付きで詳しく示す。全体Summary HTMLを一つ、各Series詳細HTMLをK個生成する。A003-A007の厳格hitを掲載し、該当なしでも各解析の実施と決定論的near-miss一件を短く残す。MMPは専用HTMLを参照し、Series詳細へ重複収載しない。

A001、A002、C012は必須入力とする。A003-A007は成功した成果物だけを掲載し、一部が明示waiveされてもPartial reportを完成させる。
