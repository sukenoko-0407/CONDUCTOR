Evidence Guide

本解析の固定仕様と評価基準です。

ΔN2T

Neighbor（またはTransferred pairのcounterpart）からTarget／Target-like側への、EndpointのFavorable方向を考慮した差です。Targetは常に矢印の先に置きます。

  • ΔN2T ≥ +0.10：Positive N2T
  • ΔN2T ≤ −0.10：Negative N2T
  • |ΔN2T| < 0.10：Neutral。N2T Directionでは符号側に配置しますが、方向Evidenceの基準通過とは扱いません。

正負はEvidence品質の優劣ではなく、Target基準での読み取り方向だけを表します。

Direct / Transferred

DirectはTarget自身を含む実測MMPです。Transferredは別Coreの実測MMPを、TargetのAttachment位置へ構造対応付けした補助情報です。Targetの現在Fragmentが観測Pairのどちら側にも一意に対応しない場合、直接適用可能とは扱いません。

Evidence quality

  • Direct High：Targetを含む実測1-cut、または2C-A。
  • Direct Limited：Targetを含む実測2C-B。
  • Transferred High：mappingが一意または対称性同値、EnvironmentがExactまたはRadius-2一致、unique pairs ≥ 3、unique contexts ≥ 2、direction consistency ≥ 0.80。
  • Transferred Limited：Targetへ対応可能だがHigh条件の一部に届かない。
  • Not applicable：Targetの現在Fragmentへ直接対応しない。
  • Ambiguous：Attachment対応を一意に定められない。

2-cut quality：2C-A / 2C-B / 2C-X

  • 2C-A：両Retained anchorが各heavy atom 4以上で、mapping・再構成・1-cut非冗長性・retained fraction・variable sizeの標準条件を満たす。
  • 2C-B：安全条件と両Anchor最低sizeは満たすが、retained fractionまたはvariable sizeの標準条件に届かない。Limited referenceとして扱う。
  • 2C-X：小Anchor、1-cutへ還元可能、attachment／mapping／再構成不正等。Databaseへ除外理由を保持するが主Evidence表示から除外する。

1-cut / 2-cut

1-cutは単一置換、2-cutはlinker／Core部分の変換を主対象とします。2-cutは二つのRetained anchorを持ち、各Anchorがheavy atom 4以上であることを主解析への最低条件とします。

Core mapping

Exact Core、Radius-2 matched、Radius-1 matched、Attachment-mapped environment mismatchの順にTargetとの対応を区別します。図ではAttachment point＝赤、Radius 1＝オレンジ、Radius 2＝青、対応MCS＝緑、非対応部分＝灰色です。

2D Align

共通Coreで2D Alignできた比較はAlign ✓、できなかった比較はAlign ×と表示します。後者も化合物全体を表示しますが、図の向きが対応しているとは解釈しません。
